# 微博 / 抖音文案 — 职场嘴替（工作版）

> 形式参照：第一人称叙事帖（痛点开场 → 一句反问 → 产品一句话 → 它具体干什么 → 隐私说明 → 说句实话的翻车坦白 → 招募）。
> 口径与小红书验证帖一致：前 3 次免费，第 4 次起 ¥9.9/周；不编造统计数据。

## 微博版（短）

领导随口一句话，本来就该让你盯着对话框看 20 分钟吗。

“顺便把数据整理一下，周五下班前给我”——你回“没问题，肯定给您”，三个词凑齐，交付时间就钉死在聊天记录里了。回“收到”怕背锅，多解释像辩解，多道歉像全是你的错。

所以我做了个小工具，叫「职场嘴替（工作版）」：贴进领导原话，先翻译他到底在问什么，再标出哪里有坑，最后给 3 个能直接复制的版本（稳妥 / 不卑不亢 / 推进），外加一条“千万别这样回”。每版回复还要过一遍风险自检，敢替你打包票的直接拦下。

说句实话，第一版翻车了，潜台词写得像模板；现在大模型负责理解，规则负责拦截。内容只用于生成这一次回复，截图记得先打码。

内测中：发我你不敢回的那句，前 3 次免费，5 分钟内回。第 4 次起 ¥9.9/周，不好用直接说。评论区留“内测”，我私信你。#职场# #打工人#

## 使用说明

- 微博版可直接粘贴发布；话题标签可按账号习惯增减。
- 抖音版为口播稿，内是分段提示，录制时不读出来；画面建议真人出镜或录屏演示一次真实分析。
- 两版都不要额外添加未经验证的数据或效果承诺（例如“回复率提升 xx%”），与验证赛口径保持一致。
