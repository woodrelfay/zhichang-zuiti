# ¥9.9 市场验证包 — 职场嘴替（工作版）

> 目的：不靠分析断言"能赚钱"，用一轮**真人付费**决定这个产品做不做下去。
> 方式：产品先不上线，用人工在微信里 5 分钟内交付（concierge / 人肉 MVP），
> 先验证"有人肯掏钱"，再决定要不要把自动化做完。
> 定价（前 3 次免费 / ¥9.9 周卡）是**待验证假设**，不是结论。

---

## 一、测试设计

| 项 | 内容 |
|---|---|
| 周期 | 7 天（招募 2 天 + 交付 5 天，可滚动） |
| 目标用户 | 22–28 岁、上班 0–3 年、每天在微信/企微回领导和客户的人 |
| 报价 | **前 3 次免费，第 4 次起 ¥9.9 / 周**（一周内不限次，周卡到期不续自动停） |
| 交付承诺 | 用户发来截图或原文后，**5 分钟内**回：潜台词 1 句 + 风险提示 + 3 版可直接复制的回复 + 1 条千万别这样回 |
| 成本封顶 | 每个方向总花费 ≤ ¥500（含小额招募激励；本产品建议 ¥0 投流，先用内容招募） |
| 判据 | 只看真实付款，不看点赞/收藏/"想要"评论 |

### 过关线（自设验证线，不是市场数据）

沿用三选一验证赛的统一规则，落到本产品：

- **付费人数 ≥ 20 人**，或
- **曝光 → 付费转化率 ≥ 3%**

任一达标 = 过关，进正式开发；两项都不达标 = 不过关，先复盘访谈再决定换方向，
**不许把"差一点"解释成过关。**

### 四个决策指标（每单必填，见 tracking.csv）

1. **付费人数**：实际付 ¥9.9 的去重人数（退款不计）
2. **转化率**：付费人数 ÷ 有效触达（看过招募内容并私信/进群的人数，口径全程一致）
3. **每单交付分钟**：从收到消息到发出回复的耗时——决定这事能不能自动化放大
4. **复购意愿**：周卡到期时问一句"下周还续吗"，记录 续 / 不续 / 没回（口头愿意 ≠ 付费，单列不混算）

## 二、招募文案（可直接粘贴）

### 小红书帖 1（痛点共鸣型）

**标题：** 领导发来一句话，我盯着对话框看了 20 分钟

**正文：**
不是我不会回，是每句都像有坑：
回"没问题"，等于当场承诺了交付时间；回"收到"，又怕理解错了最后背锅；
多解释一句像辩解，多道个歉像全是我的错。

我最近在内测一个只做工作场景的小工具（不是那种万能高情商话术）：
它先翻译领导这句话到底在问什么，再标出哪里有坑，最后才给 3 个能直接发的版本。

内测招募中：把你不敢回的那句（截图记得打码！）发我，
前 3 次免费，5 分钟内回你：潜台词 + 风险 + 3 版回复。
第 4 次开始 ¥9.9 一周不限次——就是想验证一下，这事到底有没有人愿意付钱。
不好用直接说，不用捧场。评论区留"内测"，我私信你。

### 小红书帖 2（反面教材型）

**标题：** 千万别这样回领导（我替你们试过了）

**正文：**
❌ 领导："顺便把数据整理一下，周五下班前给我"
我以前："没问题！包在我身上，周五前肯定给您！"
——"没问题 + 肯定 + 周五前"，三个词凑齐，等于把交付时间钉死在聊天记录里。
周四晚上发现数据对不上时，这张截图就是追责证据。

✅ 它真正的意思是：新活 + 已默认时间点。
先对齐优先级再接，才是成年人的回法（具体 3 个版本太长，图里了）。

我在内测一个专门干这件事的工具：发来领导原话，先给你翻译潜台词和风险，再给回复。
前 3 次免费，内测名额不多，评论区留"内测"私信发你入口。
（截图务必打码，别把公司名和同事名字发出来）

### 职场群 / 朋友圈版

在内测一个小工具，专治"领导发来消息不敢回"：
发我原话（截图先打码），5 分钟内回你：这句话的潜台词、哪里有坑、3 个能直接复制的回复版本。
前 3 次免费，第 4 次起 ¥9.9/周不限次。想试的私聊我"内测"两个字就行，不好用不用付钱也不用夸。

## 三、交付 SOP

1. **接收**：用户发截图（提醒先打码）或粘贴原文；同时问清两个信息：对方是谁（直属领导/大领导/客户/HR/同事）、你想达到什么（争取时间/委婉拒绝/认错说明/汇报进度/确认任务/请示确认）。缺一不可，缺了先追问，别猜。
2. **计时开始**：从消息完整收到起算，目标 **5 分钟内**发出（tracking.csv 记实际分钟数）。
3. **生成**：用仓库工具出初稿（本地规则版 `node src/cli.js ...`，或配好 Key 后的网页演示/大模型版），人工过一眼：潜台词准不准、回复能不能直接发、有没有把不属于用户的责任揽下来。
4. **发出格式**（固定，别自由发挥）：
   - 🧭 他其实在问：……
   - ⚠️ 风险：……（没有就写"这句没明显坑"）
   - 💬 三个版本：稳妥版 / 不卑不亢版 / 推进版（标注各自风险自检结果）
   - 🚫 千万别这样回：……（+ 一句为什么）
5. **计数与收费**：每人第 1–3 次免费，第 4 次先发收费说明："前 3 次免费结束啦，继续用的话 ¥9.9 一周不限次，不需要可以直接停，不催。"——**只说一次，不追问、不降价挽留**，拒绝也是有效数据。
6. **收尾**：当天把每单填进 tracking.csv；周卡到期的用户统一问一次复购意愿并记录原话。
7. **异常**：遇到涉及造假进度、伪造证据、甩锅给同事的内容请求，直接拒绝并记录（这类需求不做）。

## 四、隐私红线（必须执行）

- 提醒用户发截图前**打码**：真实姓名、公司名、客户名、头像、金额、内部数据一律遮掉。
- **记录里不保存任何原始截图**：tracking.csv 只记场景、关系、耗时、是否付费等脱敏字段；聊天截图在交付完成后不转发、不留存到任何文档。
- 用户原文如需用作产品示例，先脱敏并取得本人同意，否则不许用。

## 五、赛后决策（第 7 天）

按 tracking.csv 汇总四指标，对照过关线当场结论，三选一并写明依据：
开正式开发 / 换人群或价格再测一轮 / 放弃。不许用"评论区都说好"代替付款数据。
